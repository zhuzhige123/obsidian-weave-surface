# Weave Surface

Weave 官方 Obsidian 主题（文房书桌风格）。

## 特点

- 书桌外框 + 纸卡内容区
- 深色模式鎏金描边
- 多种桌面材质（Style Settings）
- 默认：浅色胡桃木 / 深色漆器乌木

## 安装

1. 在 Obsidian **设置 → 外观 → 主题** 中浏览社区主题，搜索 **Weave Surface**；或
2. 将本仓库中的 `manifest.json` 与 `theme.css` 放入库目录：

   `.obsidian/themes/Weave Surface/`

3. 在 **设置 → 外观 → 主题** 中选择 **Weave Surface**

## 桌面材质（可选）

安装社区插件 [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) 后：

**设置 → Style Settings → Weave Surface → 桌面材质**

不选择时跟随主题默认（浅色胡桃木 / 深色漆器乌木）。
